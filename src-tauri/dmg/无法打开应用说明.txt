Clash Verge Next macOS 安装与无法打开说明
==================================================

一、正常安装
1. 将「Clash Verge Next.app」拖入 Applications（应用程序）文件夹。
2. 从 Applications 文件夹启动应用。

二、如果 macOS 提示“无法打开”“应用已损坏”或“应该将它移到废纸篓”
这通常是 Gatekeeper 对未签名或未公证应用的隔离属性提示，并不等同于应用文件损坏。

1. 确认应用已经放入 Applications 文件夹。
2. 打开“终端”（Terminal）。
3. 复制并执行下面的命令：

   xattr -rd com.apple.quarantine "/Applications/Clash Verge Next.app"

4. 重新从 Applications 文件夹启动 Clash Verge Next。

安全提醒：仅对你从可信来源下载、并确认文件完整的应用执行此命令。该命令会移除
macOS 的 quarantine 隔离属性，不会替代病毒扫描、签名验证或来源判断。

English
-------
1. Drag “Clash Verge Next.app” to the Applications folder.
2. If macOS says the app cannot be opened, is damaged, or should be moved to the Trash,
   Open Terminal and run:

   xattr -rd com.apple.quarantine "/Applications/Clash Verge Next.app"

3. Launch the app again from Applications.

Only run this command for an app downloaded from a trusted source that you have verified.
It removes macOS quarantine metadata; it is not a substitute for checking the source,
signature, or file integrity.
